# Zenvora Search

A personal, company-branded workspace with an original Zenvora logo and company name on its pages and browser tab icon. The Apps hub is a launcher of links to popular official Google products (including Search, Maps, YouTube, Gmail, Drive, Docs, Calendar, Earth, and more; it is not an exhaustive list of Google's products). These links open Google websites; Google branding, sign-in, and service terms apply there. This project is a launcher, not a copy of Google products.

Search combines public web results from Google via Serper with website shortcuts, videos saved in the owner panel, and private website lists saved by signed-in users. Search queries are sent by the server to Serper; the Serper API key is kept in the server's `.env` file and is never sent to browsers. Public web search is limited to 30 requests per minute per client address. Search history is not stored. Public web results are provider results, are paginated, and do not include every website on the internet. Result icons are loaded lazily from Google's favicon service and fall back to a local letter icon if unavailable. When a signed-in user enters a website URL in the homepage search box, it is saved to that user's private list and opened directly in the browser, outside an embedded frame. This lets sites that block framing or require their own scripts, cookies, and sign-in open normally. Each user can update their username/password and remove their own saved websites. The admin panel has a private, read-only view of account names and saved websites; passwords are never shown and are stored as scrypt hashes. Add shared shortcuts and video links in the owner panel; user accounts can save up to 500 private websites each.

## Run locally

1. Install Node.js 20 or newer.
2. Copy `.env.example` to `.env`, replace `ADMIN_PASSWORD` with your own unique password of at least 16 characters, and set `SERPER_API_KEY` to a newly rotated key from your Serper account. Never put API keys in browser code or commit `.env`.
3. Run `npm start`.
4. Open [http://localhost:3000](http://localhost:3000). Users can create/sign in to their accounts at [http://localhost:3000/account](http://localhost:3000/account); enter a website address in search to save it privately to the signed-in account. Browse the Google products launcher at [http://localhost:3000/apps](http://localhost:3000/apps), video library at [http://localhost:3000/videos](http://localhost:3000/videos), and local search at [http://localhost:3000/search](http://localhost:3000/search). Google product links open their official sites. To manage personal settings, website shortcuts, videos, and view user accounts' saved websites, type [http://localhost:3000/admin](http://localhost:3000/admin) directly into the address bar and sign in. Admin HTML and JavaScript source files are organized under `private-admin/`; admin HTML and the admin script route require an authenticated session, and the server enforces authentication for every admin API request. A separate source folder alone is not an independent security boundary.

By default, the server listens only on `127.0.0.1` and is available only from this computer. To let other people use accounts online, deploy behind a trusted HTTPS reverse proxy, configure `HOST=0.0.0.0` and `SECURE_COOKIES=true` in `.env`, and use a strong unique admin password. Do not expose the app directly over plain HTTP. If the proxy overwrites or appends the actual client address to `X-Forwarded-For`, set `TRUST_PROXY=true` so login limits can distinguish clients; never enable this for direct public traffic. Account/admin sessions expire after eight hours and are kept in memory; restarting the server signs out existing sessions. Login and registration attempts are rate-limited by client IP. Personal settings are stored in `data/settings.json`; account names, password hashes, and private websites are stored in `data/users.json`. Keep the data directory private and backed up securely. Passwords are one-way hashed; saved website URLs are readable by the admin because the admin panel is designed to show them. No search queries/history are persisted.

## Verify

Run `npm test` to check local and Serper web search behavior, owner authentication, website shortcuts, video-link validation, and settings persistence.
